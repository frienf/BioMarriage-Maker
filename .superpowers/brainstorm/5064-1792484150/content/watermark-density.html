Layout B (your pick), Lakshmi colours. Each card shows the whole page, then a crop at about print size with real text. The motif is a placeholder lotus; each deity gets its own symbol (trishul, gada, veena…), never sacred text. Tiles stay inside the text box, off the side bands.
